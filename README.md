# Spring Boot Product Service

This is a Spring Boot project, created as a reference from the Java Techie channel. It is a simple product service designed to demonstrate essential Spring Boot functionalities.

## Introduction
The Spring Boot Product Service project provides a basic implementation of a product management service. It demonstrates how to create a RESTful API using Spring Boot and integrates with a MySQL database for data storage. This project is ideal for learning the core concepts of Spring Boot development.

## Features
- RESTful API for managing products
- CRUD operations for product entities
- Integration with MySQL database
- Postman collection for API testing

## Technology
This project is built using:
- **Java**: The primary programming language.
- **Spring Boot**: For building the RESTful API.
- **MySQL**: For database management.

## Database
The application uses **MySQL** as the database to store product data. Make sure to set up a MySQL instance and configure the database connection in the `application.properties` file.

## Postman Collection
A Postman collection is available for testing the API endpoints. It includes all the required requests for product CRUD operations.

## Installation
To set up and run this project:
1. Install Java Development Kit (JDK) version 8 or higher.
2. Install MySQL and create a database for the project.
3. Clone the repository and navigate to the project directory.
4. Configure the database connection in the `application.properties` file.
5. Run the application using the Spring Boot starter class.

## Usage
The project provides APIs for:
- Adding a new product
- Retrieving product details
- Updating existing product information
- Deleting products

Use the Postman collection for testing these endpoints.
