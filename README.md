# 🔐 Custom Login with UI in Spring Boot

This is a fully working Spring Boot project that demonstrates how to customize the default login experience using a user-defined login page.

---

## 🚪 Default Behavior

By default, accessing:
https://localhost:8080/login


...shows the **Spring Security** default login page.

In this project, we override that behavior and provide a **custom login UI** tailored to the application's needs.

---

## 📚 What You'll Learn

- How to replace the **default Spring Security login page** with your own **HTML/CSS login form**
- How to **configure Spring Security** to point to your custom login page
- Insights into **useful built-in classes and configurations** in Spring Security

---

This project is ideal for understanding the **basics of securing web applications with a custom user interface in Spring Boot**.
